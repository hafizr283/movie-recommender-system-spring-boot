# Educative - Spring 6 and Spring Boot 3 Course

This repository contains lesson-wise projects and code from the course **The Complete Guide to Spring 6 and Spring Boot 3** on Educative.

## Overview

The course is available through the GitHub Student Developer Pack. This repository serves as a personal learning log, where every lesson's corresponding project is tracked and stored. For more details about the course, please refer to the original course link.
